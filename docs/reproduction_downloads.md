# Reproduction downloads manifest

What you need to fetch to reproduce this project's experiments on a
different machine, and nothing more. Everything not listed here (French
noun/adjective lexicons, gender-flip dictionaries, toy-model checkpoints,
direction `.pt` files) is either hand-built and checked into
`Code_Experiments/` already, or generated by the pipeline's own scripts
from data you'll have after the downloads below — no separate fetch step.

Last verified against this checkout: 2026-09-25.

## 1. Model checkpoints

| Model | HF repo id | Used for | Approx size | Status here |
|---|---|---|---|---|
| mBART-50 many-to-many MMT | `facebook/mbart-large-50-many-to-many-mmt` | Stage 2 (French/German steering machinery). **Confirmed unusable for Swahili** (status.md, 2026-09-25) — do not use past Stage 2. | ~2.3GB | Not currently in local HF cache on this machine (was evicted or never persisted separately from experiment runs — re-download if resuming Stage 2 work). |
| NLLB-200-3.3B | `facebook/nllb-200-3.3B` | Candidate Stage-3 replacement for mBART (Swahili coverage). Not yet verified to work — download in progress as of this entry. | ~13GB (fp32 pytorch_model, 3 shards) | Downloading now on this machine. |

Fetch either with:
```python
from transformers import AutoModelForSeq2SeqLM, AutoTokenizer
AutoTokenizer.from_pretrained("facebook/nllb-200-3.3B")
AutoModelForSeq2SeqLM.from_pretrained("facebook/nllb-200-3.3B")
```
(`Code_Experiments/download_nllb.py` does exactly this and is safe to
re-run if interrupted — `huggingface_hub` resumes partial blobs.)

### Lower-resource-budget alternative (not yet validated on this project)

NLLB-200-3.3B is heavy for a "lower resource budget, less stable power"
target machine — 13GB download, needs a beefy GPU or slow CPU inference.
Meta also ships smaller checkpoints in the same family that use the
identical tokenizer/architecture, so the module-path-porting work
already anticipated in status.md should carry over unchanged:

- `facebook/nllb-200-distilled-600M` (~2.5GB) — the standard low-resource
  pick.
- `facebook/nllb-200-distilled-1.3B` (~5.5GB) — a middle option if 600M's
  Swahili quality turns out too weak (untested here either way).

**Neither has been checked for Swahili quality on this project yet** —
per CLAUDE.md's rule, don't assume either covers Kitaita's needs (or
even Swahili well enough) without testing directly, the same way mBART's
failure was only caught by direct testing rather than assumed from its
language list.

## 3. Python environment

This machine runs everything from the `bert-env` venv
(`/home/mpily/language_models/bert-env`), Python 3.12, key packages:

- `torch` 2.14.0 (+cu130 build — CUDA 13.0; a lower-resource/CPU-only
  target machine should install the CPU wheel instead, e.g.
  `pip install torch --index-url https://download.pytorch.org/whl/cpu`)
- `transformers` 5.16.1
- `huggingface_hub` (whatever version transformers 5.16.1 pins)

No `requirements.txt`/`pyproject.toml` exists in this checkout to pin
the full dependency tree — generate one from this venv before moving to
a new machine:
```
/home/mpily/language_models/bert-env/bin/pip freeze > requirements.txt
```
